Base64

在这里分享最基础的base64题目处理~

Base64是一种把二进制数据编码成文本的编码风格，它使用64个字符编码数据
一个字节有256种不同的数据（8bit，而一个base64字符有64种数据（6bit
就相当于把256位的东西转换成64进制的东西，可以把它想象成一个进制转换

4位base64可以表示3个字节（一个base64字符只能表示64种情况，要表示256种情况就要更大的空间，不足的用=补齐）

常见变形：1.修改编码表，2.修改下标
1：比如把原本0对应的A改成Q，但是不管怎么改，index没变
所以只需要反推index，再去标准表里找到对应的值是多少就行，写出标准表对应的字符串之后再用标准表的解码函数进行解码

例子：

2：把base64的编码查表下标对应关系修改，对于这种修改，我们只需要推到出下标逆运算即可
识别：

一，找字符串 二，看等号 三，看0x3F

脚本：
最常用：

import base64

编码：字符串 → Base64

text = "#待输入" encoded = base64.b64encode(text.encode()).decode() print(f"编码: {text} → {encoded}") # aGVsbG8=

解码：Base64 → 字符串

decoded = base64.b64decode(encoded).decode() print(f"解码: {encoded} → {decoded}") # hello

之前讲解了x86架构的，今天来说说x64的函数调用约定~ 与x86不同，x64在调用之前用mov来把参数传给寄存器（前四个是传给寄存器，分别是rcx，rdx，r8，r9，后面的mov进栈）之后再call，进入call之后，再mov把寄存器里的参数传进栈中，再push rbp保存旧的rbp，然后sub提升栈顶，这里又有所不同，x86是mov ebp，esp，然后ebp就呆在原本保存旧ebp的地方，x64不同，它通过lea传给rbp一个esp+0xn的地址，地址与rsp之间的空间，正是留给参数，留作该函数后续再调用其他函数时，mov参数所用而rbp也不在原本保存旧的rbp的地方了，就不能说rbp+4是参数了~ 感觉和x86比起来不是很喜欢x64呢
