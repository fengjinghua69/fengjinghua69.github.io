x86 function calling conventions

发表于2026-11-07|更新于2026-11-08|笔记
|浏览量:

在这里我分享x86架构下栈帧调用的细节与流程~

调用时，先存入参数，再call->先存下一步的地址

再push ebp 存入EBP原来的位置之后mov ebp, esp->提升栈底到栈顶位置

然后再sub一下开辟空间，然后push保存寄存器->解放他们方便用来计算

然后给局部参数（是ebp-0x4这样开始给）

然后结束之后，还原，mov esp,ebp，把esp拉下来，原本开辟的空间不要了，
这个时候刚刚好，欸，到了这个存放ebp这个地方，
再pop ebp还给它。然后到了那个红色的，存放下一条指令的地方，
pop之后呢，下面的参数直接进行一个ADD，把ESP给还原掉，参数顺道也不要了

（这一步取决于调用约定如果是 cdecl 就是调用者 add esp, X；
如果是 stdcall，则是被调用者在 ret 时直接 ret X顺便平栈）

x64-function-calling-conventions
之前讲解了x86架构的，今天来说说x64的函数调用约定~ 与x86不同，x64在调用之前用mov来把参数传给寄存器（前四个是传给寄存器，分别是rcx，rdx，r8，r9，后面的mov进栈）之后再call，进入call之后，再mov把寄存器里的参数传进栈中，再push rbp保存旧的rbp，然后sub提升栈顶，这里又有所不同，x86是mov ebp，esp，然后ebp就呆在原本保存旧ebp的地方，x64不同，它通过lea传给rbp一个esp+0xn的地址，地址与rsp之间的空间，正是留给参数，留作该函数后续再调用其他函数时，mov参数所用而rbp也不在原本保存旧的rbp的地方了，就不能说rbp+4是参数了~ 感觉和x86比起来不是很喜欢x64呢

the usage of DOSBOX
我们可以使用DOSBOX来运行old的文件~这里我分享DOXBOX的使用方法！ DOSBox 默认的 Z: 盘是系统模拟盘，不能直接放游戏。你需要用 mount 命令，把电脑上的一个真实文件夹映射成 DOSBox 里的 C 盘。 1. 准备游戏文件夹：在你的电脑上（比如 D 盘或 E 盘）新建一个文件夹，专门用来存放 DOS 游戏，例如 D:\DOSGames。 2. 执行挂载命令：在 DOSBox 窗口中，输入以下命令后按回车： 12mount c d:\dosgames 命令说明：mount 是挂载指令，c 代表 DOSBox 中的 C 盘，d:\dosgames 是你电脑上实际存放游戏的路径。 3. 切换盘符：挂载成功后，输入 c: 并按回车，就切换到了虚拟 C 盘，提示符会变成 C:>。 4. 进入游戏目录：用 cd 命令进入具体游戏所在的子文件夹，例如： 1cd game_folder 5. 运行游戏：输入游戏的启动文件（通常是 .exe 或 .bat 文件）名。可以先输入 dir 命令查看目录下有哪些文件，找到可执行文件后，输入文件名并按回车即可运行。
